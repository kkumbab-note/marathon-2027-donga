# 2027 동아마라톤 훈련 스케줄

2027년 3월 21일 동아마라톤 완주를 목표로 한 20주 훈련 스케줄 웹앱이에요.

- **기본 목표**: 3시간 40분 완주
- **도전 목표**: 3시간 30분 완주
- **훈련 기간**: 2026.11.02 – 2027.03.21 (회복 4주 + 본 훈련 16주)

---

## 실행 방법

별도 설치 없이 브라우저에서 바로 열 수 있어요.  
단, 아래 세 파일이 **같은 폴더**에 있어야 정상 작동해요.

```
📁 같은 폴더
├── 2027_동아마라톤_훈련스케줄.html   ← 브라우저로 열기
├── pretendard.woff2
└── 동아마라톤_330_완주_러너.png
```

`2027_동아마라톤_훈련스케줄.html` 파일을 브라우저로 열면 바로 사용할 수 있어요.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 오늘의 훈련 | 현재 날짜 기준 당일 훈련 자동 표시 |
| D-Day 카운트 | 대회까지 남은 날 자동 계산 |
| 월간 훈련 달력 | 월 탭 전환, 날짜 클릭 시 훈련 상세 조회 |
| 훈련 선택지 | 컨디션에 따라 대체 훈련 옵션 선택 |
| 20주 거리 / 진행률 | 주차별 계획·실적 비교표 |
| 월별 거리 집계 | 월 단위 km 합산 |
| 기록 저장 | 완료·건너뜀·메모를 브라우저에 자동 저장 |
| 백업 · 복원 | JSON 파일로 기록 내보내기 / 가져오기 |

---

## 훈련 타입

| 타입 | 설명 |
|------|------|
| `E` | 이지런 |
| `L` | 롱런 |
| `MP` | 마라톤 페이스 |
| `NSM` | 서브역치 |
| `TR` | 트레일 |
| `S` | 보강 |
| `X` | 휴식 |
| `점검` | 기록 점검 (10km / 하프) |
| `대회` | 동아마라톤 풀코스 |

## 기술 스택

- **순수 HTML / CSS / JS** (프레임워크 없음, 외부 의존성 없음)
- **Pretendard** 폰트 (SIL OFL 1.1 라이선스)
- **localStorage** 기반 훈련 기록 저장
